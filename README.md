# spark_chat

适用于讯飞星火大模型 V3.0 的跨平台客户端

## 1. 安装依赖

```bash
flutter pub get
```

## 2. 配置密钥

在根目录创建 `.env` 写入密钥

```bash
# APIKEY & APISECRET from https://console.xfyun.cn/services/bm3
APPID='xxxxxxxx'
APIKEY='xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'
APISECRET='xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'
```

## 3. 运行

```bash
flutter run
```
